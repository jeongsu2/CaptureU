# CaptureU

> 내 계정에서 잘된 릴스와 내가 고른 참고 계정(1~3개)을 분석해서, 다음 릴스의 **캡션 첫 줄 후킹 문구**와 **썸네일 구성안**을 추천하는 인스타그램 크리에이터용 서비스

## 주요 기능

- **내 계정 분석:** 게시물의 조회수, 저장, 스킵률을 모아 잘된 릴스와 나머지의 차이를 찾는다.
- **참고 계정 비교:** 직접 고른 계정 1~3개의 잘된 릴스를 같은 기준으로 비교한다.
- **추천:** 다음 게시물의 첫 줄 후보와 썸네일 구성안을 근거와 함께 보여 준다.
- **효과 확인:** 추천 문구를 쓴 게시물의 스킵률과 저장률을 내 평소 값과 비교한다.
- **초반 반응 추적 (선택):** 원하는 사용자만 게시 직후 반응이 좋은 릴스를 알려 준다.
